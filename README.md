# Adaptive-Traffic-Signal-Optimization-using-Reinforcement-Learning-in-SUMO
The project uses Q-learning, a model-free reinforcement learning algorithm. The agent interacts with the traffic environment and learns optimal actions based on rewards.
Traffic congestion is a major challenge in modern urban environments, leading to increased travel time, fuel consumption, and pollution. Traditional traffic signal systems operate on fixed timing schedules, which are inefficient under dynamic traffic conditions.

This project presents an intelligent traffic signal control system using Reinforcement Learning (Q-learning). The system dynamically adjusts traffic signal phases based on real-time traffic density using the SUMO (Simulation of Urban Mobility) platform.

The goal is to minimize congestion and improve traffic flow by allowing the system to learn optimal signal strategies through interaction with the environment.
2. Objectives
The main objectives of this project are:

• To design an adaptive traffic signal control system
• To implement Q-learning for decision-making
• To simulate real-world traffic scenarios using SUMO
• To reduce vehicle waiting time and congestion
• To compare performance with traditional fixed signal systems
3. Technologies Used
• Python (Core implementation)
• SUMO (Simulation of Urban Mobility)
• TraCI (Traffic Control Interface)
• Q-Learning (Reinforcement Learning algorithm)
• Matplotlib (Performance visualization)
